## Advanced Topics and Workflows

### 3D LUT Creation

3D LUTs (Lookup Tables) are powerful tools for color transformation in video and gaming applications. DisplayCAL can create accurate 3D LUTs for various purposes:

* [3D LUT creation workflow for Resolve](wiki-3d-lut-resolve.md) - Creating and using 3D LUTs with DaVinci Resolve
* [3D LUT creation workflow for madVR or eeColor](wiki-3d-lut-madvr-eecolor.md) - Setting up 3D LUTs for high-quality video playback
* [3D LUTs for Direct3D and OpenGL applications (using ReShade)](wiki-3d-lut-reshade.md) - Implementing color management in games and other 3D applications

### Advanced Calibration Setups

* [Setting up untethered](wiki-untethered.md) - How to configure and use DisplayCAL in an untethered configuration

## Compatibility

DisplayCAL works with a wide range of colorimeters and spectrophotometers through ArgyllCMS. For a full list of supported devices, refer to the [ArgyllCMS documentation](https://www.argyllcms.com/doc/ArgyllDoc.html).
